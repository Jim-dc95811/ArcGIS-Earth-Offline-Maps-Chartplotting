# Contributing

Field reports, reproducible bugs, and documentation corrections are welcome.

When reporting a problem, include the ArcGIS Pro/Earth version, Windows/Android version, the exact tool/package version, and the smallest repeatable sequence that shows the issue. Do not upload licensed imagery or operational/sensitive incident data.

For production logic changes, test on copied data and a non-critical destination first. The project favors small, isolated changes over broad refactors.
